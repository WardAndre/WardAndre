## Sobre

Sou desenvolvedor de software com experiência profissional em aplicações web com **React e JavaScript**, integração com APIs e colaboração com equipes de tecnologia. Atualmente, foco meus projetos em **desenvolvimento backend com Java e Spring Boot**, APIs REST, PostgreSQL e testes automatizados.

## Projetos em destaque

### [Metopa](https://github.com/WardAndre/metopa)

Plataforma de publicação e leitura de quadrinhos em desenvolvimento. O backend utiliza **Java 25, Spring Boot 4, Spring Modulith e PostgreSQL**, com APIs REST, autenticação, persistência de dados e testes automatizados com **JUnit 5 e Mockito**. A aplicação adota uma arquitetura de **monólito modular**.

### [Apolo](https://github.com/WardAndre/apolo)

Projeto experimental de rádio online automatizada com **Python, FastAPI, PostgreSQL e Docker**, integrando **Liquidsoap, FFmpeg e streaming HLS**. A geração de música instrumental por inteligência artificial faz parte dos objetivos do projeto e permanece em desenvolvimento.
